# 👥 KeenKeeper — Keep Your Friendships Alive

KeenKeeper is a friendship management web application that helps users stay connected with friends, track interactions, set relationship goals, and maintain meaningful friendships.

## ✨ Key Features
- 👥 View and manage friend profiles.
- 📅 Track last contact dates and relationship goals.
- 📞 Log Call, Text, and Video interactions.
- 📜 View and filter interaction history.
- 📊 Friendship analytics with interactive pie charts.
- 🔔 Toast notifications.
- 📱 Fully responsive design.
- 🚫 Custom 404 page.

## 🛠️ Technologies Used
- React.js
- React Router
- Tailwind CSS
- DaisyUI
- Recharts
- Lucide React
- JSON
